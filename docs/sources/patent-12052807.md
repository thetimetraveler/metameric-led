## Claims (summary)
- **Claims 1, 7, 13 (controller, method, storage device):** At each of several ambient temperatures, drive each LED emitter alone with the others off; record optical measurements and photodetector electrical measurements at each drive current; derive a temperature-dependent relationship between each emitter's optical output and drive current; store it.
- **Dependent claims:** use the stored data to set drive currents for a requested spectrum; test at 100%, 30% and 10% of maximum drive current; measure luminous flux and x/y chromaticity; use photocurrent or forward voltage from the photodetectors; receive optical measurements wirelessly from a remote device.

## Description (summary)
- **Photodetector measurement:** Dedicated photodetectors measure the photocurrent induced by each emission LED while it runs at operating current. Phosphor-converted LEDs can be split into two spectral portions measured by different detector colors.
- **Forward voltage (Vfe / Vfd) and temperature:** Measured with a small non-operating current to limit the effect of parasitic resistance that builds up with aging. Emitter and detector forward voltages indicate junction temperature.
- **Calibration:** Typically at two temperatures (~25 °C and ~70 °C), stored in a table; compensation interpolates for the current operating temperature. Photocurrent readings help account for aging, and phosphor efficiency loss is tracked separately.
- **Maintaining color:** Red is affected by temperature more than green or blue, so the color point drifts as the fixture warms. Compensation adjusts each LED's drive current to hold flux and chromaticity at target.
