# Features

Each feature has its own page with its design, the decisions made so far, and open items. They are listed in the order they get built.

1. [Colour mixing](colour-mixing.md): turns a target colour and brightness into five channel levels.
2. [Temperature compensation](temperature-compensation.md): corrects colour drift as the strip heats up.
3. [Optical feedback](optical-feedback.md): the in-fixture sensor that measures and corrects the light.
4. [Calibration](calibration.md): instruments, jig and procedure for building each fixture's calibration table.
5. [Fixture matching and aging](fixture-matching-and-aging.md): keeps fixtures matched to each other and over the years.
6. [Home Assistant integration](home-assistant-integration.md): how the lights appear and are controlled in Home Assistant.
